# Hivee Social Media Platform

Hivee is a desktop-based social media platform developed using C#, .NET Windows Forms, and SQL database systems. The project was designed to simulate the core functionalities of modern social networking applications by combining interactive user experiences with scalable backend logic and structured database management.

The platform includes a complete social interaction system featuring user authentication, profile management, friend requests, real-time messaging, posts, comments, and media sharing. Users can interact with each other similarly to popular social media platforms through a responsive and event-driven desktop interface.

The application was built using object-oriented programming principles and modular software architecture to ensure maintainability and scalability. SQL databases were used to manage persistent storage for users, messages, interactions, and multimedia content.

## Key Features

* User Authentication & Account Management
* Friend Requests & Social Connections
* Real-Time Chat & Messaging
* Posts, Comments, and User Interactions
* Media Sharing System
* Responsive Windows Forms GUI
* SQL Database Integration
* Modular and Scalable Architecture

## Technologies Used

* C#
* .NET Framework / Windows Forms
* SQL Database Systems
* Object-Oriented Programming (OOP)
* Event-Driven Programming
